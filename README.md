
# **SPK Pemberian Bantuan Pengembangan Desa Wisata**  

Proyek ini merupakan **Sistem Pendukung Keputusan (SPK)** untuk pemberian bantuan pengembangan desa wisata, menggunakan **Flask** sebagai backend dan **React.js** sebagai frontend. Sistem ini dirancang untuk membantu dalam proses pengambilan keputusan dengan mempertimbangkan berbagai kriteria, seperti **daya tarik wisata, amenitas, digitalisasi, kelembagaan & SDM, serta resiliensi**.  

### **Teknologi yang Digunakan**  
- **Backend**: Flask (Python), SQLAlchemy, MariaDB  
- **Frontend**: React.js, Tailwind CSS  
- **API**: RESTful API untuk komunikasi antara frontend dan backend  

### **Fitur Utama**  
✅ **Manajemen Data Desa Wisata** (Tambah, Ubah, Hapus, Lihat)  
✅ **Evaluasi & Peringkat Desa Wisata** berdasarkan kriteria yang telah ditetapkan  
✅ **Sistem Autentikasi Pengguna** (Login & Role-Based Access)  
✅ **Visualisasi Data** untuk analisis hasil evaluasi  

### **Cara Menjalankan Proyek**  
1. **Pasang database** `upwisatasleman` yang tersedia dalam file ZIP.  
2. **Jalankan Backend**  
   ```bash
   cd backend
   python app.py
   ```  
3. **Jalankan Frontend**  
   ```bash
   cd frontend
   npm install
   npm start
   ```
